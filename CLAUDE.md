# Research Agent — CLAUDE.md

## What this is

A local-first research and study assistant built on top of the existing Digital Lab RAG.
It adds: ReAct harness, wiki auto-generation, session context pre-loading,
multi-format ingest (including omics), and global MCP registration.

**The existing ChromaDB with 3,746 chunks is reused directly — nothing is re-indexed.**

## Architecture at a glance

```
USER QUERY  (CLI / Claude Code MCP / OpenCode MCP)
     │
     ▼
agent/context_builder.py       ← pre-loads wiki nodes into system prompt
     │
     ▼
agent/harness.py                ← ReAct loop (qwen3:8b via Ollama /api/chat)
     │
     ├── search_memory()        ← wiki → ChromaDB → Engram (budget-capped)
     ├── save_insight()         ← wiki/auto/ + Engram
     ├── save_feedback()        ← wiki/manual/feedback/ + Engram
     └── call_cloud()           ← OpenRouter (gated, public-only)
     │
     ▼
knowledge_base/                 ← EMBEBIDO en este repo (autónomo, portable)
  src/                          ← motor RAG (vector_store, embeddings, router)
  config/topics.yaml            ← mapeo topics → colecciones ChromaDB
  data/chroma_db/               ← índice vectorial (gitignored, rebuild con setup.py --rebuild)
  input/                        ← tus PDFs y docs (Git LFS)
  Collections: transf_digital | nexus_ia_bigdata | emprendimiento |
               agente_inmobiliario | web_development
```

## Instalación (primera vez o después de mover/clonar)

```bash
# macOS / Linux
python3 setup.py

# Con rebuild (después de git clone — ChromaDB vacío)
python3 setup.py --rebuild

# Windows — doble-click en setup.bat
# o desde terminal:
python setup.py --rebuild
```

`setup.py` detecta el OS automáticamente y:
- Crea `knowledge_base/data/chroma_db/` e `knowledge_base/input/` si no existen
- Actualiza `config.yaml` (solo la ruta del binario engram)
- Instala dependencias pip
- Registra el MCP en Claude Code (cualquier directorio)
- Instala el watchdog como servicio OS (LaunchAgent / Task Scheduler)
- Con `--rebuild`: re-indexa todo `knowledge_base/input/` en ChromaDB

## CLI usage

```bash
# macOS/Linux
python3 agent/assistant.py "¿Qué es la transformación digital?"
python3 agent/assistant.py --interactive --topic "transformacion digital"
python3 agent/assistant.py --status
python3 agent/assistant.py --context-only "query"

# Windows (mismo comando con python en lugar de python3)
python agent\assistant.py "query"
python agent\assistant.py --interactive --topic "tema"
```

## MCP tools (available in Claude Code from any directory)

| Tool           | Description                                      |
|----------------|--------------------------------------------------|
| search_memory  | wiki-first RAG retrieval (budget-capped)        |
| save_insight   | persist synthesis to wiki/auto/ + Engram        |
| save_feedback  | persist evaluator feedback                       |
| call_cloud     | gated OpenRouter escalation                      |
| agent_status   | ChromaDB + wiki + Ollama health check            |
| ingest_files   | add files to the knowledge base                  |

## Supported file formats

Standard: pdf, docx, xlsx, txt, md, csv, json, html
Omics:    fasta, vcf, bed, wig, tsv, gtf, gff
Rejected: fastq, fastq.gz, bam, cram (generate QC summary first)

## Adding new files

```bash
# Drop file into inbox/ — auto-ingested by watcher
cp paper.pdf data/public/inbox/

# Or ingest directly
python3 agent/assistant.py --ingest paper.pdf

# Force a specific topic
python3 infra/ingest/run_ingest.py paper.pdf --topic TRANSF.DIGITAL
```

## Wiki nodes

- `wiki/auto/` — auto-generated by the model after high-confidence answers
- `wiki/manual/` — your own Obsidian-compatible notes (place .md files here)
- `wiki/manual/feedback/` — evaluator feedback saved by save_feedback tool

Both are searched before ChromaDB to minimize context cost.

## Key paths

| Path | Purpose |
|------|---------|
| `config.yaml` | Single config — edit model, thresholds here |
| `knowledge_base/input/` | Pon tus PDFs/docs aquí (Git LFS) |
| `knowledge_base/data/chroma_db/` | Índice vectorial (gitignored, rebuild con --rebuild) |
| `knowledge_base/src/` | Motor RAG embebido |
| `knowledge_base/config/topics.yaml` | Mapeo topics → colecciones ChromaDB |
| `wiki/auto/` | Auto-generated knowledge nodes |
| `wiki/manual/` | User-curated wiki (Obsidian) |
| `data/public/inbox/` | Drop files here for auto-ingest |
| `data/private/` | Private notes (gitignored, never sent to cloud) |

## Model

Default: `qwen3:8b` via Ollama. Change in `config.yaml → llm.local.model`.
Minimum recommended: any 7-8B quantized model (Q4_K_M or better).
